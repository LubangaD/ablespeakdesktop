AbleSpeak Tier 2 — the ten screens

The dashboard's UI, refreshed 13 October 2026. Open any screen below.

These files follow the app as it is today: the grey-blue palette and Roboto Flex from dashboard/src/lib/ui.js. They replace the six screens in ../stitch/, which are still on the earlier navy palette the app no longer uses. See README.md for the class-to-constant mapping and what changed.

Not in this folder

The voice bar

The part the student uses all day is not a dashboard page: it is server/overlay.html, a transparent always-on-top window. Its own rules are in docs/design/DESIGN.md under "The student overlay" — text in rem and never under 16px, only the mic button, no keyboard hint, and every resting state says what to say next. Home and the Test console draw its state, never a live microphone.
