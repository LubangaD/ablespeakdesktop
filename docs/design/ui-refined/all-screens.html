uia_act

Screen Try in Test console

Description

Act on a control in the front window through Windows UI Automation, using the pattern the control itself supports — Invoke, Value, Scroll, ExpandCollapse or SelectionItem. Does not move the mouse, so it cannot miss, and costs nothing per call.

Parameters

target required
The control’s name or automation id, as read_screen reported it
pattern required
One of Invoke, Value, Scroll, ExpandCollapse, SelectionItem
value
The text to set, for the Value pattern

Function schema

{
  "name": "uia_act",
  "description": "Act on a control in the front window through its own UI Automation pattern.",
  "parameters": {
    "type": "object",
    "properties": {
      "target":  { "type": "string", "description": "Name or automation id" },
      "pattern": { "type": "string",
                   "enum": ["Invoke","Value","Scroll","ExpandCollapse","SelectionItem"] },
      "value":   { "type": "string", "description": "For the Value pattern" }
    },
    "required": ["target", "pattern"]
  }
}
