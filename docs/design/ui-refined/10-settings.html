Who can open what

Admin PIN

Opens Test console, Developer Hub and Settings. An unlock lasts 15 minutes. Five wrong tries pause unlocking for five minutes.

Set

The first admin PIN can only be set from the tray icon (Set admin PIN…), within 10 minutes of choosing it there. It cannot be set from this page.

Helper PIN

Opens Users and Exams, and nothing else — no keys, no logs, no Developer Hub. For a teacher or aide who only manages people and their progress. Optional, and it cannot be the same as the admin PIN.

Not set
